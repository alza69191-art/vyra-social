# VYRA Social

A monochrome social network starter built with Next.js 15, TypeScript and Supabase-ready architecture.

## Brand
- Name: VYRA
- Mark: white V inside a black circle
- Palette: black, white and neutral grays only

## Run locally
```bash
npm install
npm run dev
```

## Environment
Copy `.env.example` to `.env.local` and add the Supabase project URL and anon key when backend integration begins.

## Current milestone
Responsive Arabic RTL social dashboard with navigation, stories, post composer, feed interactions, discovery preview and creator/community shortcuts. The visible demo data is local UI state and is not yet persisted.
